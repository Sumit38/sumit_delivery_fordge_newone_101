📊 HOW IT WORKS (User Flow)
================================================================================

1. User registers with email (Clerk)
2. Completes profile (mobile, organization, role)
3. Goes to dashboard
4. Pastes requirement document
5. Clicks "Analyze Complexity"
6. Claude API analyzes requirement
7. Identifies nodes (decision points) & edges (paths)
8. Your algorithm calculates: M = E - N + 2P
9. System shows: "You need X test scenarios"
10. User writes exactly X justified test cases ✓
